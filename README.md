# 🎾 Tennis Point Tracker

### Computer Science NEA | Swift • SwiftUI • Firebase

A tennis point-tracking application developed as part of my **Computer Science NEA**.
This was my first experience working with **Swift, SwiftUI and Firebase**, allowing me to explore iOS application development, user interface design, data management and backend integration.

> 🚧 **Project Status:** Work in Progress — Prototype


## 📌 About

The **Tennis Point Tracker** was designed to provide a simple way of recording and tracking points during tennis matches.
The project followed an iterative software development process:

**Analysis → Design → Development → Testing → Evaluation**

The application represents an important stage in my development as a programmer, as I was learning a completely new programming language and set of development tools while building the project.


## 🛠️ Technologies

|---|---|
| **Swift** | Core programming language |
| **SwiftUI** | User interface development |
